# Craft Agents Documentation Index

This source points to the public Craft Agents documentation site (https://agents.craft.do/docs/) so the agent can reference setup guides, source docs, and best practices.

Scope
- Docs, HOWTOs, and reference pages covering sources, skills, automations, MCP servers, and workspace configuration.

Guidelines
- This is a read-only documentation source (no authentication required).
- Use it to discover setup steps and recommended patterns for adding additional sources and skills.

Examples
- Find the MCP setup guide for a specific provider (e.g., Linear or GitHub)
- Look up `sources.md` and `skills.md` for workspace conventions

Notes
- This is a helpful complement to web search when verifying provider endpoints or setup hints.
