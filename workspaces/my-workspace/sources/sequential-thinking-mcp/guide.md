# Sequential Thinking MCP Guide

This source provides tools to facilitate a structured, progressive thinking process. It helps break down complex problems into sequential thoughts across defined stages like Problem Definition, Research, and Analysis.

## Key Tools
- `process_thought`: Record a new thought in the sequence.
- `generate_summary`: Get an overview of the entire thought process.
- `clear_history`: Reset the thinking process.
- `export_session` / `import_session`: Save and load your thinking sessions.

For detailed documentation on the tools and their parameters, please refer to the official repository:
[https://github.com/arben-adm/mcp-sequential-thinking](https://github.com/arben-adm/mcp-sequential-thinking)
